# v5.3 交互规格书（逐关逐手势 · 供 codex 对抗评审）

> 在已签字的 v5.2 玩法框架上，把每一关钻到"每个元素的数字、每个手势的反馈、每句语音"。
> 评审标准升级为：**WarioWare Gold 级的即时可读性与爽感**（3 秒懂目标、每次点击都有汁水、每关有一次翻转），
> 但终极目的永远是"教会数学 + 点燃好奇"。

## G. 全局交互律（先审这一章）

### G1 数字出现三律（回应"每个元素都有数字"）
1. **目标数永远可见**：警报数字、座位容量"0/7"、终点石墩号、十仓"8/10"——目标从第一秒就是数字。
2. **数过/放下的实物立刻得到数字徽章**：孩子每点一个待数实物或每放置一个实物，该实物右上角出现序号徽章
   （1,2,3…），同时：容器计数器 +1、实物头顶 numPop 浮出大数字、SFX 音高逐级上升、TTS 报数（child-count 通道）。
   —— 一次点击 = **五维反馈**：徽章 / 计数器 / 浮字 / 音高 / 语音。
3. **没数过的实物故意不带数字**：数数是孩子的工作。结构件（石墩刻度、格子编号、阶梯 2/4/6/8）永久带数字，
   因为它们是"尺子"；散落的待数物不带，因为它们是"题"。

### G2 语音三律（回应语音规则）
1. **孩子的交互立即打断/快进语音**（现有 cutSay：答题、放置、数数、重听均打断；数词回声不被掐）。
2. **页面自然播报绝不自我打断**：旁白按队列顺序说完（现有队列）；页面事件等语音（afterSay）。
3. **演示可快进**：任何"演示/揭示动画"期间，点屏幕任意处 = 快进到结果帧 + 语音跳到总结句（新增全局手势）。

### G3 WarioWare 节奏律
1. **动词横幅开场**：每关开场 0.8 秒打出一个大字动词（摆！/配对！/配平！/剪！/投！/跳！）+ 对应音效，
   随后一句 ≤8 字的目标语音（"做出一样多！"）。3 秒内孩子可以开始动手。
2. **每关一次翻转**（twist reveal）：结构显形的瞬间必须伴随一次"哇"（自动排队/折叠成阵/锁仓盖章/彩虹重合/残影重跳/永不平衡）。
3. **失败零羞辱、重试零等待**：错误反馈 ≤1.5 秒（指出差在哪），立即可再试；连续卡住才进演示。

## W1 会排队的泥点
**元素与数字**：目标布幕上显示"记住了吗？"（不显数量——数量是题）；脚印按钮无数字；
孩子每踩出一个泥点→泥点得徽章 1,2,3… + numPop + 报数；右上角构造计数器「你做了：4」实时变。
**交互表**
- 点脚印 → 溅出一个泥点（随机位置，pop 弹跳）+五维反馈。
- 点已有泥点 → 它"缩回地里"（反向动画），计数器 −1，报"少一个，三"。
- 点「冲呀」→ 提交。水花掀起 → 乱泥空中翻滚 0.9s → **啪啪啪落成 2×5 十格**（每落一个格位亮一下+短鼓点）；
  原题泥点同步排成上行对照，逐列绿闪核对（对一列"叮"一声）。
- 对照差异：缺→空格闪黄+语音"还差两个"；多→多的泥点自己跳回脚印+语音"多了一个"。
- L2 两色：红蓝泥点在十格里**分色显示**（红占前 a 格、蓝接着排）→ 算式 a+b=n 从格框抽出。
- L3 雨：雨幕 1.2s，被冲走的泥点滑出画面时各自浮出一个灰色徽章（原编号），语音"冲走了三个"。
- L4 篮下：构造区在右侧小格板（同规格 2×5 缩小版），提交后篮子起飞，藏着的泥点带着徽章现身逐个对位。
**语音脚本**：开场"摆！做出一样多！"；每点一下报数；提交后总结"你做了五个——和刚才一样多！五！"

## W2 救援配对拉链
**元素与数字**：每只海龟头顶空狗位剪影（无数字）；**配好的每一对**得到共享徽章 1,2,3…（挂在安全带中点）；
右上角「救到：3/6」容量计数器；L4 双座舱侧面印"×2"，阵列折叠后边缘亮 2/4/6/8（永久尺子）。
**交互表**
- 点待命狗 → 狗滑坡道（0.5s）跑向最近落单海龟 → 安全带"拉链"动画连成对 + 五维反馈（报的是**对数**）。
- 全部配对 → 自动提交：安全带全部绷直"唰"，对数徽章依次跳动复数一遍。
- 多点狗 → 坡道门温和关闭，狗摇头回队（无声惩罚仅 0.6s，不报错语音）。
- L3 点名：车厢里的狗，点一只亮一只+徽章+报数；重复点已亮的 → 徽章晃一晃+语音"它已经数过啦"；
  点完最后一只 → 车顶数字牌"哗啦"翻出总数（翻牌动画）。
- L4：点狗=派双座舱；舱滑下自动吸附一对海龟（吸附瞬间舱顶亮"2"）；按「出发」提交；
  成功 → 舱阵折叠成 2×d 网格，网格边缘从上到下亮 2、4、6、8 并逐个报（auto-count 通道）。
**语音脚本**：开场"配对！一只狗救一只龟！"；错位反馈"还有两只海龟没有狗！"（缺口海龟闪黄同时说）。

## W3 公平大天平
**元素与数字**：两个托盘上方各有**实时数字气泡**（左 3 右 5，随增减跳动）；横梁中央有水平指示灯（歪=红，平=绿）；
地面饼干堆无数字（待分的题）。
**交互表**
- 点地面饼干 → 飞上"当前该放的盘"（L3 强制交替，飞错边自动改道并有弧线提示）+五维反馈（报该盘新数量）。
- 点盘中饼干 → 飞回地面，盘数字气泡 −1。
- 板子角度 = (右−左)×3.2°，缓动 0.35s；每次变化横梁"吱呀"一声，接近水平时音调变纯净。
- 放平瞬间：**"当~"钟声 + 横梁水平灯变绿 + 两侧数字气泡碰杯动画（3=3）**。
- L1 谁多多几：配平所加的每一块单独用金色徽章计数（1,2），平了之后金徽章飞进"多几个"的 □。
- L3 单数：最后一块拿在手（跟随指针/浮在中央），先试左（左沉 0.4s）再试右（右沉 0.4s）→ 退回中央聚光灯，
  孤块缓缓旋转，语音"七是单数——总有一块配不成对"。双数结局：最后一块落下即绿灯+彩带。
- L4 自由平分：全部分完且左=右的最后一块落下才判定（n 只出偶数 6/8/10/12）；
  分完但不平 → 重盘弹出一块跳回地面+语音"这边太重啦"（不计错）。
**语音脚本**：开场"配平！让板子平平的！"；总结"两边都是四——公平！四加四等于八！"

## W4 花结与彩虹
**元素与数字**：藤上每个葫芦下挂位置小牌 1–7（永久尺子，序数关的核心可读物）；花结无数字；
L4 顶部彩虹收集架显示"已收集 1+6 ✓"（收集品带算式）。
**交互表**
- L1/L2 点葫芦 → 正确：停摆→落地→白烟变身+徽章"第3个"；错误：该葫芦晃头，从起点侧起**位置牌逐个闪到它**
  （视觉重数一遍），语音"这是第五个哦"。
- L3/L4 点花结 → 剪刀出现咔嚓（0.3s）→ 藤分两段弹开摆动 → 左段滑进左筐与剪影逐个重合（每合一个+徽章+报数）。
- L4 彩虹：两段藤各自卷成弧（长度∝数量，双色），拼成总长恒定的彩虹条；剪出镜像分法时两条彩虹旋转 180° 重合
  （0.8s）+语音"换个边，还是七！"；收集架打勾并显示"2+5 ✓"。
- 剪错位置：两段回弹接合（0.4s），左筐剪影缺/多的位置闪黄，语音"左边要三个，现在只有两个"。
**语音脚本**：开场"剪！把七剪成三和几？"；彩虹集齐"七的分法全找到了！一和六、二和五、三和四！"

## W5 能量十仓
**元素与数字**：十仓每格底部印格号 1–10（永久尺子）；数码屏实时显示"8"；第二仓出现时屏变"10 和 □"；
门口排队的能量球无数字（待投的题）；英雄头顶无数字（叙事件）。
**交互表**
- 点排队英雄 → 跑进机器把球投进下一个空格（球滚入格子发光 0.25s）+五维反馈（报格号=当前总数）。
- L1 红队投完换蓝队时，机器"换弹匣"音效+屏闪一下颜色。
- L2 断电：传送门吸球（格子逐个熄灭+灰徽章飘出）→ 孩子逐格点亮剩余格清点（点名机制，重复点无效+提示）。
- L3 缺口：全息格闪烁频率=缺口数的心跳感；点传送门→补一颗亮一格；满员再点→"嗡"+屏抖动一下。
- L4 凑十：第 9 颗入仓时屏跳"9"，第 10 颗入仓瞬间**全仓金光→锁扣咔哒→盖"10"章→整仓收拢成一根十条**
  （1.2s，此期间点击可快进）；余球自动排入第二仓，屏显"10 和 3"；最后一颗入仓即提交，屏翻牌"13"。
**语音脚本**：开场"投！把能量装满！"；凑十总结"十个装成一盒——十和三，十三！"

## W6 三颗仙桃
**元素与数字**：石墩刻度 1–12 永久可见（双数金色仅 L2）；仙桃架 ×3（吃一颗变桃核）；
每跳的弧顶浮出这一跳的跨度数字（+1/+2 小徽章挂在弧上）；终点石墩号大号发光。
**交互表**
- 点「跳1」/「跳2」→ 悟空（骑棒）起跳弧线动画 0.45s，弧顶徽章+落点报数（"八！"）+仙桃变核。
- 三跳用完自动提交：到达→金门庆典；未到/超过→悟空荡回起点（0.6s），仙桃恢复，
  上次弧链变虚影保留+语音"一加二加一是四，还差一格"。
- 成功：**金色残影从起点用另一种排列重跳**（弧顶同样挂跨度徽章），双方落同一石墩；
  三段弧下沉叠成一根 5 格金箍棒，棒身浮出"2+2+1=5"。跨十弧在金门自动分色蓝金。
- L3 翻倍镜像段（保留 v4）：虚影段滑出时，虚影上浮出"再来一个 4"。
**语音脚本**：开场"跳！三颗仙桃跳到十二号！"；残影落地"顺序不一样，落点一样！"
