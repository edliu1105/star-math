## 1. [严重] 掌握门让稳定全对的孩子无法解锁 —— 已修，并加了正向回归测试

你说得完全对：`recentRate` 要求 `hist.length>=8`，而 `hist` 每达成一次 4/5 窗口就被清空，
所以全对的孩子每 5 题清一次窗，`recentRate` 恒为 0，**永远解锁不了**。这是我上一轮改动引入的正向死锁。

修法：**拆成两套历史**
- `hist` —— 升/降级的滑动窗口，达成窗口后清空（原行为不变）
- `recent` —— 近期正确率专用，滚动保留最近 12 条，**永不清空**

`recentRate()` 改用 `recent`。

**新增 G7 正向掌握测试**（`tests/test_gates.py`），这是这条 bug 的回归测试：
```
第 1 次启动后：{'lv': 3, 'mast': 12, 'wins': 1, 'tries': 12}
第 2 次启动后：{'lv': 4, 'mast': 24, 'wins': 2, 'tries': 24}
  [OK] 全对后难度升到 L2 以上（实际 L4）
  [OK] 累计掌握 >=6（实际 24）
  [OK] 跨两次启动拿到 2 个掌握窗口（实际 2）
  [OK] 近期正确率 >=0.6（实际 1.00）—— 说明 recent 没有被 hist 的清窗连带清掉
  [OK] ★ 稳定全对的孩子确实解锁了第三个世界
```

## 2. [严重] 成人门可在同一道题上快速连点绕过 —— 已修

- 首次点击**同步**置 `gaAnswered=true` 并**立即禁用整排按钮**，换题前的窗口里再点无效

```
  [OK] 答错后验证门立即关闭

  [OK] 同一道题上快速连点正确按钮，不能凑够连对两题
```
