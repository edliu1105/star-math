# iPad 真机验收清单

自动化测试跑在 Playwright **WebKit**（iPad Safari 的同源引擎）上，但**真机的音频会话、静音开关、TTS 声音、主屏 PWA、GPU/内存**无法用无头浏览器代表。
下面这些请在 iPad 上各做一遍，一共约 10 分钟。任何一条不过，把现象告诉我即可。

## A. 首次打开（Safari）

| # | 操作 | 期望 |
|---|---|---|
| A1 | 扫码打开网址 | 直接进入星空入口页，不跳转到别的域名，地址栏是 `https://` |
| A2 | 点中间的大喇叭按钮 | **立刻听到中文女声**"欢迎来到星星回家…"，并进入世界地图 |
| A3 | 如果没听到声音 | 顶部应自动出现**黄色喇叭提示条**；点它应该再说一遍 |
| A4 | 把 iPad 侧边静音开关打开（静音） | 语音和音效**仍然能听见**（无声 `<audio>` 会把页面提升为媒体会话） |
| A5 | 连续快速点同一个物体 8–10 下 | 语音不卡死、不排长队；**画面上的编号和大数字一个都不少** |

## B. 语音健壮性

| # | 操作 | 期望 |
|---|---|---|
| B1 | 玩一关，中途按 Home 切出去，再切回来 | 语音能继续工作（不需要重开页面） |
| B2 | 玩到一半锁屏，解锁回来 | 同上 |
| B3 | 点左上角房子回地图，再进另一个世界 | 上一个世界的语音不会串进来 |
| B4 | 数数时快速连点 | 数词可以只报最新一个，但**绝不能卡死不出声** |
| B5 | 「设置 → 辅助功能 → 朗读内容 → 声音」把中文声音删掉后再打开应用 | 仍然**完全可玩**（全靠画面），并且出现喇叭提示条 |

## C. 家长面板（真机排查工具）

| # | 操作 | 期望 |
|---|---|---|
| C1 | 右下角**长按 3 秒** | 弹出成人算术验证（不是直接进面板） |
| C2 | 答对算式 | 进入面板，能看到：系统声音总数、中文声音数量、当前所选声音、**首句是否成功** |
| C3 | 点「测试发声」 | 听到"一，二，三。你好，我是语音测试。" |
| C4 | 把面板里显示的这几项拍照发我 | 用于排查任何语音问题 |

## D. 添加到主屏幕（PWA）

| # | 操作 | 期望 |
|---|---|---|
| D1 | Safari → 分享 → 添加到主屏幕 | 图标是深蓝夜空 + 金星星，名字「星星回家」 |
| D2 | 从主屏图标启动 | **全屏无地址栏**；第一次点喇叭按钮仍然立刻出声 |
| D3 | 主屏模式下横竖屏各转一次 | 布局都完整，**任何画面都不需要上下滑动** |

## E. 离线

| # | 操作 | 期望 |
|---|---|---|
| E1 | 联网玩一遍六个世界各一关（让素材进缓存） | — |
| E2 | 打开飞行模式，从主屏图标重新启动 | 能正常打开、图片全在、**六个世界都能玩** |
| E3 | 关掉飞行模式，刷新一次 | 能拿到最新版本（页面是网络优先） |

## F. Chrome for iPad

把 A1–A5、D3 在 Chrome 里再跑一遍（iPad 上的 Chrome 也是 WebKit，但音频策略略有差别）。

## G. 性能感受（主观即可）

| # | 观察 | 期望 |
|---|---|---|
| G1 | 进入世界的等待 | 首次约 1–2 秒（显示"准备中"），之后几乎瞬间 |
| G2 | 连续玩 15 分钟、来回切世界 20 次 | 不发烫、不卡顿、不闪退 |
| G3 | 动画 | 星星飞行、角色跳动都顺滑 |

---

## 出问题时怎么给我信息

1. 打开家长面板，截图那一屏（声音诊断那几行）。
2. 说清楚：Safari 还是 Chrome、是不是主屏模式、静音开关的状态、哪个世界哪一步。
3. 如果是画面问题，横屏/竖屏各截一张。
