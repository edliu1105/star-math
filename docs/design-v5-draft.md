# 星星回家 v5 设计草案（供 codex 对抗性评审 · Round 1）

## 要推翻的核心问题（v4 的病根）
v4 的每一关本质都是：**看一段动画 → 从四张数字卡里选一张**。数学发生在"验证动画"里，不发生在孩子手上。
装饰性动画（拍立得、雨、传送门）再多，交互内核仍是选择题。这就是"不惊艳"的根源。

## v5 设计哲学（三条铁律）
1. **一个世界 = 一个可上手的"数学玩具"**。四个难度不是换参数，而是同一个玩具的四次"规则扭转"（twist）。孩子进 L2 的第一反应应该是"咦，这次它变了！"
2. **答案用构造表达，不用四选一**。孩子通过摆、切、放、跳、配平来"做出"答案；数字符号只在最后作为"你刚才做的东西的名字"出现。
3. **每个世界一个"魔法时刻"**：玩具自己把数学结构显形出来的瞬间（意料之外），而孩子回想时会发现"本来就该这样"（情理之中）。

## 全局签名动画：「数字是名字」
每关结束时，孩子刚构造出的实物（比如摆好的 3 个泥点）**缩小、飞进算式的 □ 里，凝固成数字 3**。
实物→符号的桥在每一关的最后一秒重演一次。这是全 App 统一的仪式。

## 世界一 · 佩奇泥坑 →「记忆泥格」
**玩具**：一块 2×5 的十格泥地（大格子，一直在场）。泥点闪现在格子里，孩子**凭记忆把图样重新摆出来**（点空格生成泥点，再点取消）。
- L1 快照重摆：闪 4–7 个（骰子/双排结构位）→ 遮住 → 孩子在空泥格上重摆 → 揭底逐格对照（对的亮绿，漏的亮黄）。
- L2 两跳合并：先闪红 a 个、再闪蓝 b 个（不同格）→ 孩子要摆出**合起来**的样子 → "3 和 2 合起来是 5"。
- L3 雨水冲走：闪 n 个 → 大雨当着孩子的面冲掉 k 个（看得见哪几格没了）→ 摆出**剩下**的。
- L4 篮子捉迷藏：闪 n 个 → 篮子扣住一部分格子，只露出 a 个 → 孩子在旁边的小格板上摆出**被扣住的**那部分 → 篮子飞走对照。
**魔法时刻**：揭底时逐格对照的"绿灯雨"，以及摆好的泥点飞进 □ 变成数字。
**为什么深**：瞬识 + 工作记忆 + 结构化位置 + 合成/分解，全在同一块泥格上发生；答案是"摆出来"的，不是"选出来"的。

## 世界二 · 冒险湾 →「出动大坡道」
**玩具**：消防局大坡道 + 底部一排**看得见座位的救援车**（座位=虚线剪影位）。狗狗从坡道滑下去坐进座位（一次一只，滑梯动画+入座 pop）。
- L1 警报出动：警报亮出数字 n → 车上正好 n 个座位 → 孩子点狗滑下入座，坐满即走。**多点一只会挂在车尾摇摇欲坠提示超载**（不会直接判错，是玩具反馈）。
- L2 补队缺口：车上已坐 a 只，座位共 n → 只需再滑 n−a 只。空座位一直闪。
- L3 归队点名：任务结束，车回来，k 只跳下车跑回狗窝（点名板划叉）→ 车上还剩几只？孩子这次**用手电筒逐个照亮车上剩下的狗来数**（点一只亮一只报一个数），数完说答案。
- L4 海龟双载：每只狗背上驮 2 只海龟滑下来 → 阶梯表 2/4/6/8 亮 → "d 只狗驮了几只龟"。
**魔法时刻**：超载狗挂车尾晃悠（幽默的"多了"具象）；车开走时座位数字逐个亮起唱数。
**为什么深**：基数原则（座位一一对应）、缺失加数（空座）、减法（下车）、倍数（背上的 2）。

## 世界三 · Bluey 后院 →「公平大天平」
**玩具**：一台巨大的跷跷板天平（全场唯一主角），两个托盘。饼干是可点的：点地上的饼干飞上指定托盘，点托盘里的饼干飞回地面。板子角度连续物理缓动。
- L1 谁多多几：a 和 b 自动上盘，板子倾斜 → 孩子往轻的一边**一块一块加**，每加一块报一个数，加平的瞬间"当"一声水平 → "你加了 2 块，所以 Bluey 多 2 块！"**差 = 配平所需的量**，这是差的操作性定义。
- L2 指定配平：只许给 Bingo 加（Bluey 的盘锁住）；先出算式 b+□=a。
- L3 单双数审判：n 块饼干，孩子一块一块轮流发到两盘（左右左右）→ 双数：最后一块落下时板子水平锁定+彩带；**单数：板子永远差一点，轻轻摇摆不停（永不平衡动画），最后一块孤零零站在中间聚光灯下**。"单数 = 永远摆不平的数"。
- L4 平分预言：先让孩子预言"每人几块"（点数字），然后亲手轮流发牌验证；发完板子水平 → 预言应验。
**魔法时刻**：单数关的"永不平衡的摇摆" + 孤块聚光灯。一次就记住单双数。
**为什么深**：比较、差、奇偶、除法雏形全部落在同一个物理隐喻（重量/平衡）上。

## 世界四 · 葫芦山 →「藤蔓与剪刀」
**玩具**：一根挂着葫芦的长藤（v4 的藤保留）。新道具：**剪刀**（点两个葫芦之间的空隙就咔嚓剪断，藤分两段各自弹开摆动）。
- L1 藤上第几个：正向序数，摘下变身（保留 v4，它已经对）。
- L2 倒着数：反向序数（保留）。
- L3 剪出算式：藤上 N 个葫芦，算式 x+□=N → 孩子**选择在哪个空隙下剪**，剪对了两段分别数数落进两个筐。剪的位置=分解的选择。
- L4 分法大收集：「把 7 剪成两段，有几种剪法？」每剪一次，头顶的**数字彩虹**点亮一道弧（1+6、2+5、3+4）；藤自动愈合再剪；集齐所有弧 → 彩虹完整绽放。**数的分解全家福**。
**魔法时刻**：彩虹逐弧点亮到完整绽放；剪刀咔嚓+两段藤弹开。
**为什么深**：序数方向性 + 分解是"选择切点"这个空间动作 + bonds 的系统性（一个数的所有分法）。
**新素材**：剪刀（SVG 或 imagegen）、彩虹弧（SVG 渐变）。

## 世界五 · 复仇者 →「能量十仓」
**玩具**：大厦顶的能量机器，核心是一个**十格能量仓**（横排 5+5 大格）+ 侧面数码计数屏。英雄一个一个走进格子（每格站一个英雄，格子充能发光）。
- L1 充能集结：昆式机空投 a 个 + 传送门 b 个，全部走进仓（红格/蓝格）→ 读总数。
- L2 撤离断电：仓里 n 个，k 个被传送门吸走，**格子逐个熄灭** → 剩几格亮？
- L3 全息缺口：任务需要 n，已有 a 站好，缺的格子全息闪烁 → 孩子**点传送门补人**，补一个亮一格（不是选卡，是补到刚好）。
- L4 凑十爆仓：已有 8 个，又来 5 个 → 前 2 个填满十仓，**十仓"锁定"金光一闪盖上"10"的印章**，多的 3 个溢出滑进第二个仓 → "10 和 3，十三！"**凑十法的物理版**。
**魔法时刻**：十仓锁定盖章 + 溢出滑落。十进制的第一次心跳。
**为什么深**：十格阵从"旁边的图示"升级为"游戏场地本身"；凑十、进位、十几的结构全部可见。
**新素材**：机器外壳/能量格（CSS 发光即可，必要时 imagegen 一张机器底图）。

## 世界六 · 花果山 →「金箍棒数轴」（保留骨架，换 L4）
**玩具**：12 格石墩数轴 + 骑棒小悟空（v4 保留：每格一蹦、弧线、双数金轨、镜像翻倍）。
- L1 接着数（保留）。
- L2 二连筋斗（保留：只有 +2 按钮，双数刻度金色）。
- L3 如意变变变（保留：镜像分身滑出接上）。
- L4 **智慧跳**（新）：同时给「跳 1 格」「跳 2 格」两个按钮，目标 11/12，十号石墩是金门。挑战：**用最少的跳数到终点**。跳完统计"你用了 5 跳！悟空说他只要 6 跳——你赢了他！"（或者"还能更少吗？再试一次"）。跨十的那一跳弧线自动在金门处分成蓝金两截（凑十）。
**魔法时刻**：发现"2 格跳更省"的那一刻（乘法直觉的种子）；金门分弧。
**为什么深**：数轴 + 计数策略选择（组合 1 和 2）+ 跨十分解，孩子第一次"优化"。

## 需要 codex 评审的问题
1. 逐世界打分（1–10 分，标准="意料之外情理之中的惊艳感 + 数学深度 + 3.5 岁可操作性"），低于 8 分的必须给出更强的替代方案。
2. 每个"魔法时刻"是否真的成立？哪些是我一厢情愿？
3. 交互负荷：3.5 岁孩子的精细动作（点空隙剪藤、摆格子）是否可行？给出降级方案。
4. 工程可行性红线：单文件 vanilla JS + 现有角色素材 + 少量新 SVG/imagegen 道具；哪一条设计会爆炸？
5. 你自己的更好的点子：任何世界如果你有明显更惊艳的方案，直接推翻我的。
6. 素材清单：哪些必须 imagegen，哪些 SVG/CSS 就够。

评审完请给出：逐世界结论表 + 必改清单 + 你的替代方案。我们目标是双方都愿意在"这套设计足以惊艳一个挑剔的家长"上签字。
