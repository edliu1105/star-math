## 全局（继承已签字 G 律，本轮新增四条）
1. **四个输入适配器**（架在四内核之上）：DockedTap（对象到站冻结+宽域点按，绝不漏车）/
   ZoneScrub（离散区域穿越判定，禁像素覆盖率）/ RotaryQuantizer（旋转分扇区累计，可停可反转可续抓）/
   PathCorridor（只判路径进入哪条宽走廊，不评线条美丑）。
2. **数学状态离散化，物理效果预制化**：判定只吃量化 payload；水流、抛射、卷曲、切割全部是预制结果动画。
3. **操作预算（闭环）**：L1 有效操作 ≤5 次、L2/L3 ≤7 次、L4 ≤4 个宏步骤；禁止重复劳动伪造难度。
   每关重复量显式上限：W1L1 n≤5 跳；W2L1 n≤5 厢（**入厢后自动发车**，一厢一点）；W2L2 N≤6 区；
   W2L3 装弹+发射合计 ≤7；W3L3 配对 ≤3 对；W5L1 **电梯预置 5 位已就位**，孩子只补 n−5 位（n∈8–10，≤5 点）；
   W6L3 p≤3 颗（拖 3 次）。
   **L3 层规则（收窄表述）**：L3 的每一步必须是"有数学意义的确定动作"（自主选择集合/捆/罐/配对，
   或亲手执行一次数学变换如 ×2 穿门），仍然禁止"无意义连点直到系统喊停"；
   其中 W2L3、W6L3 属"构造完成型"——数学在每一步动作里（装弹选量/亲手翻倍），完成构造即提交。
4. **语音由 countChanged 驱动**（不由动画回调）；中间数可合并、最终数不可丢；点按兜底只替代手势输入、
   不替代数学选择（旋钮点一下走一扇区、描弧点一下选一种跳距）。
   payload 必含 targetN/startX/requiredK/layoutId/motionSeed/answerSet/toleranceProfile/priorEvidence。
   imagegen 上限 2 张（海湾缆车远景、蟠桃园远景），一切数量证据与交互前景=SVG/CSS。

## W1 佩奇 —— 主线【事件计数 → 合成 → 减去指定部分 → 求隐藏部分】（点 → 轨道滑 → 拖 → 描弧盖章）

**L1 泥坑蹦床·跟着跳（点）**
佩奇跳 n 下（鼓点+泥花+闪数），乔治眼巴巴等着。孩子点乔治蹦床跟跳同样多次（每点一跳一鼓点），
第 n 下后自动提交。数"事件"而非"东西"。翻转：对上→两猪同步齐跳，脚下泥花排成一行逐个亮数。
差错反馈：跳多→乔治头晕坐下"多跳了一下"；跳少→佩奇歪头示意"还差两下"（虚影脚印提示缺几）。

**L2 生日蛋糕装莓果（轨道滑）**〔codex 必改 1：去泥，改生日蛋糕〕
订单卡：红莓 a + 蓝莓 b。果盘到蛋糕之间有两条弧形轨道，孩子**把莓果沿轨道滑上蛋糕**
（起手即吸附轨道，滑到头落进下一个果位——ZoneScrub 轨道版，落点=种子果位）。
提交进烤箱→翻转：蛋糕转一圈，莓果自动排成红上蓝下两行，插上总数蜡烛，烛光即 a+b。

**L3 睡前收玩具（拖）**〔R1 等价案：非泥主题；孩子的选择决定结果〕
客厅里 n 件玩具（SVG：积木/皮球/小汽车），猪妈妈说"收 3 件进箱子就够啦"。
孩子**拖任意 3 件入玩具箱**（箱口有 3 个虚线位，放一件亮一位）。第 3 件落箱即提交。
翻转：箱子合盖蹦一下，地上剩下的玩具排成一行自动报数——"收走 3 件，还剩 4 件"，减法算式从箱盖抽出。
拖多→第 4 件被箱盖轻轻顶回"箱子说：够啦！"。

**L4 魔术帽藏猫猫（描弧偷看 + 盖章提交）**〔R2：偷看免费无限，提示不替孩子盖章〕
猪爸爸魔术：n 个泥点列队报总数，帽子罩住一部分只露 a 个。
孩子可**沿帽檐描一道小弧=掀缝偷看 1 秒**（免费、可反复——偷看是策略不是惩罚对象），
然后用印章在答题板**盖出藏住的数量**（盖一下一个章+报数），点"变！"提交。
翻转：帽子腾空，藏着的泥点戴礼帽列队走出，与孩子的章逐个击掌；对不上时多/缺的章自己脸红摇头。

## W2 汪汪队 —— 主线【一一对应 → 稳定计数 → 部分与整体 → 两个一组】（到站点 → 擦 → 瞄准拖 → 摇柄）

**L1 靠站缆车（DockedTap）**〔R3：到站冻结，无错过无超时；一厢一点〕
警报数字 n（n≤5）。缆车厢滑进站台后**完全停住**，孩子点狗→狗跳进厢占座，**该厢自动发车**、下一厢自动进站停稳。
装满 n 节自动出发跨海。翻转：过海时车厢底部 1…n 逐节亮灯唱数，海面倒影同步。

**L2 骨头雷达·分区扫描（ZoneScrub）**〔R4：离散区域，一次穿越即锁定〕
雷达屏亮出 N 个大号微光区（种子位置）。孩子用**宽扫描刷擦过每个光区**（路径穿过一次即锁定弹出骨头+报数）。
挖满 N 根，狗狗打滚。点按兜底=逐区点挖。翻转：骨头自动搭成 1–N 阶梯塔，狗叼最后一根登顶插旗。

**L3 磁轨救生圈（选量装弹 + 瞄准拖）**〔R5 + 增加数量选择：装弹数就是答案〕
顶部 N 格总量条：岸上 k 只海龟已占 k 格（灰），水中每只对应一个空格。
第一步（数学选择）：孩子从救生圈堆**拖救生圈装进弹舱**——要救水里的全部，该装几个？装好按"出发"。
装少了→发射完弹舱空响"咔哒"，水里还有海龟闪黄"还有两只没圈"（补装再发，不计错）；
第二步：逐发**拖发射器对准光环松手**，救生圈沿预制轨道套住一只（对应格点亮）。
全部套完提交。翻转：岸上队与新救队并排对照，总量条收缩成 N−k 的减法算式——弹舱装的数就是答案。

**L4 双倍鱼饼机·四段摇柄（RotaryQuantizer）**〔R6：四扇区磁吸，可停可反转；d 限定偶数〕
摇柄圆周分四个大扇区，**拖过一个扇区吸附保存**，凑满四段=一整圈=吐 2 块鱼饼（左右各喂一只狗）。
d 只狗排队（d∈{4,6}，圈数=d/2≤3）。点按兜底=一点走一扇区。
翻转：纸带按实际圈数打出 2、4、…、d，撕下变成对应的 2+2(+2)=d 横幅挂机身（d 动态生成）。

## W3 Bluey —— 主线【比较 → 差 → 两个一组 → 平分】（点 → 强吸附拖 → 相邻滑配对 → 调整+切线）

**L1 影子怪兽比高（点）**〔R7：三次有意义点按替代机械叠块〕
后院夜晚，投影灯把 Bluey 和 Bingo 的影子打在墙上。点 Bluey 的灯→她的影子按订单数**逐格长高**（一格一报数）；
点 Bingo 的灯同样；第三次**点更高的影子**完成判断。
翻转：矮影子头顶补出差值虚格（缺 2 格的轮廓闪烁），"高 2 格"从墙上抽出。

**L2 后院跷跷板（强吸附拖）**
拖饼干上两个托盘配平（一维吸附轨道，起手即入轨）。差=配平所用块数（金徽章）。放平"当~"+数字碰杯。

**L3 月光双人舞·相邻配对（滑）**〔R8：孩子亲手构造"两个一组"〕
N 个点心排成横队。孩子**从一个点心滑到相邻点心**=两人牵手成舞伴双双进场（已配对锁定）。
双数：全部成对，舞池彩带；单数：剩最后一个自然独舞聚光灯（无处可配是构造出来的事实）。
翻转：独舞者鞠躬"下次帮我带个朋友来"——"加 1 变双数"的种子。

**L4 镜像餐盘披萨（调整拖 + 走廊切线）**〔R9：槽位交换 + 中心走廊判定〕
披萨左右各有固定樱桃槽位，初始错放 1–2 颗。孩子**拖樱桃换边**直到两列逐行对应，
然后**沿中心宽走廊划一刀**（PathCorridor：只判穿过走廊）。
翻转：两半分盘飞到姐妹面前逐颗对数，"6 分成 3 和 3"。切歪→披萨自己转正重试（无惩罚）。

## W4 葫芦山 —— 主线【序数 → 反向序数 → 合成 → 分解】（点 → 单轴滑 → 选捆拖 → 走廊分流）

**L1 藤上摘瓜（点）**：藤上 7 葫芦挂位置牌，点第 n 个→落地白烟变身（保留）。

**L2 悬崖吊篮（单轴滑）**
山壁 7 层洞穴。任务"从上往下数第 m 层"。孩子**上下滑吊篮**（一格一停一报"从上数第二"）送葫芦娃进洞。
翻转：送对后全部层牌集体翻面显示"从下数"的编号——同一个洞两种数法，方向性显形。

**L3 炼丹炉·药草整捆（选捆拖）**〔R10：判断缺少量=选对捆〕
炉沿 N 个可见槽已亮 x 格。桌上 2–3 捆**带点阵的药草捆**（如 2、3、4 点装）。
孩子**选一整捆拖入炉口**：对的捆拆开逐株填满空槽（报 x+1…N）；错的捆先预演"还空一格/多一格"再弹回。
翻转：投对后炉盖打开，药丸滚成 x+□=N 的分合队形，火焰只做庆祝（不当探测器）。〔搭桥：槽位语言沿用 L2 的"第几格"〕

**L4 七彩瀑布分流（走廊描切）**〔R11：弃藤；正整数无序分法；不跨局强制〕
崖顶瀑布的水珠排成 N 个发光节点（N≤6）滑向分流口。孩子**沿宽弧水道描到某个分流门**，
水珠分成 a 与 N−a 两股彩虹瀑布落进两潭（1+5、2+4、3+3；排除 0+N；镜像门即时折叠为同一张证据卡）。
一局收集 2–3 种无序分法即通关。翻转：集齐时两潭彩虹升起相接成整圆，"6 的分法"卡册哗啦翻页。

## W5 复仇者 —— 主线【数到十 → 识别补数 → 选择补数 → 十和几】（点 → 缺口匹配拖 → 三选一甩 → 多步装车）

**L1 英雄电梯（点）**：楼层灯 1–10，**电梯里已预置 5 位英雄（楼层灯已亮到 5）**。
任务 n∈8–10：孩子点英雄补进电梯（进一位升一层报一层"六、七、八"），到 n 层"叮"（≤5 次点按）。
从 5 接着数——顺带埋下"从中间起数"的种子。翻转：玻璃轿厢升起，英雄在窗口逐层探头挥手。

**L2 盾牌缺口补丁（缺口匹配拖）**〔R12：连续缺口 + 整条扇区条三选一〕
盾牌十格环缺一段连续扇区（如缺 3）。桌上三条不同长度的扇区条（2/3/4 格，点阵+数字双编码）。
孩子**拖一整条对准缺口**：正好→咔哒合体，盾旋转飞出一圈回来；不合→预演"少一格/多一格"后弹回。
"7 和 3 合成 10"直接长在盾上。

**L3 凑十能量炮·三选一（甩）**〔R13：数学决定发炮〕
仪表已亮 7 格。小怪举"7"的牌子晃。桌上三只能量罐（2/3/4，点阵+数字）。
孩子**选一罐甩进炮膛**：只有 3 罐能正好充满 10 →全炮金光发射，光束打出"7+3=10"，小怪弹回传送门。
错罐短暂显示"差一格/溢一格"完整弹回。甩依然爽，判定在选择。

**L4 十号仓库（多步：拖十箱 + 点散箱）**
发货"13"：传送带送来封装十箱（十格纹理），孩子**拖上卡车**（"这一箱就是十！"），
再**点散箱**逐件装 11、12、13（车侧两段屏"10 和 3"）。
翻转：卡车开走瞬间十箱透明化 1 秒露出内部整齐 10 件——"十箱里真的有十个"。

## W6 花果山 —— 主线【+1 → +2 → 每份变二 → 三步组合】四关四场景（点 → 重复滑 → 逐颗拖 → 三次描弧）

**L1 石墩数轴桥（点）**：点石墩逐格搭桥，骑棒悟空逐格蹦（保留，唯一桥场景）。

**L2 筋斗云升空（上滑）**
云海场景+垂直高度表 1–12（双数金）。**向上滑一次=翻两筋斗升 2 层**（2、4、6 唱数，云翻滚）。
到达唐僧所在高度。翻转：云炸成小云朵拼出到达数字，高度表留下一串弧形跳痕。

**L3 蟠桃穿分身门（逐颗拖）**〔R14：每个 1→2 由孩子亲手触发〕
蟠桃园。枝上 p 颗桃，园中立一座**分身门**。孩子**逐颗把桃拖过门**→穿门瞬间裂成两颗，
分别吸入上下两条对齐槽（报 p+1…2p 连续数）。处理完 p 颗，槽里 p 对整齐排列=2p。
翻转：门里的悟空冲孩子做鬼脸，随后两条槽合并压弯枝头，"3 的两倍是 6"从枝头抽出。

**L4 龙宫三跃夺神针（三次描弧走廊）**〔R15：弃天空避免与 L2 重复〕
龙宫珊瑚数字台（台号 6–12），定海神针插在终点台，10 号台是发光龙门。三颗仙桃=三跳。
每步只亮**距离 1 与距离 2 两条宽弧走廊**，孩子描进其一（PathCorridor）。
出题保证总和 ∈{4,5} 且成功序列必含 1 和 2。三跳完自动提交；
成功→金色悟空残影按**另一种不同排列**重跳（确定性规则选取），双双落在神针台，
三段弧压成一根金箍棒浮出"2+2+1=5"，跨十弧在龙门分蓝金两截；悟空拔起神针举过头顶。
失败→荡回起点、仙桃复原、上次弧链留虚影"一加二加一是四，还差一格"。
