## 0. 设计哲学
- v4 病根：看动画 → 四选一。数学发生在验证动画里，不在孩子手上。
- v5：**一个世界 = 一条核心数学主线 = 一个核心手势动词**。答案用构造表达（甩/拖/滑/拽/切/抛/描弧），
  构造中的点击永不计错；算式永远后置——先动手，结构显形之后算式才从证据里抽出来。
- **WarioWare Gold 标准**：0.8s 动词横幅开场（只显示不朗读）+ ≤8 字真实指令语音，3 秒内可动手；
  每关一次"翻转时刻"（≤900ms 的结构揭示）；失败反馈 ≤1.5s 零羞辱即时重试。

## 1. 全局系统

### 1.1 星轨（标题变玩法）
每通一轮，本关数学证据（十格线/配对轨/天平梁/彩虹弧/十仓框/跳跃弧链）收拢成一截发光星轨飞上世界地图；
**每轮一段、共 10 段**（=现有十星，两次 session 集满），十段全亮星座绽放。每轮只入账一次（防动画重入）。

### 1.2 数字三律（修订版）
1. 题目明确给出的目标数永远可见（警报数字、"目标 8｜已装 3/10"两段屏、终点石墩号）；**考回忆数量的题除外**。
2. 数过/放下的实物立刻获得反馈（见 1.3 反馈工具箱）；结构件（石墩刻度、阶梯 2/4/6/8、位置牌 1–7）永久带数字——它们是尺子。
3. 没数过的散落实物故意不带数字——数数是孩子的工作。（十仓格子不编号：2×5 结构本身就是尺子。）

### 1.3 反馈工具箱（禁止五维全开）
每次有效操作从工具箱选 3±1 维：徽章 / 容器计数器 / numPop 浮字（出现后 240ms 缩入徽章合体）/ 音高逐级上升 / TTS 报数。
- W1：徽章+计数器+浮字缩入+报数；W2：共享对徽章+计数器+拉链声+报对数（无浮字）；
- W3：左右数字气泡+音效+报数（饼干无徽章，仅 L1 配平块金徽章）；W5/W6：仓屏/弧跨度徽章（无追加浮字）。
- 自动揭示阶段只用灯光+节奏音+结构动画，**零逐物 TTS**。
- 删除实物：剩余徽章 160ms 内无声重排为 1…n，语音只说"现在三个"。

### 1.4 语音仲裁（唯一规则）
- 孩子交互立即打断/快进语音；页面旁白按队列绝不自我打断（现有机制保留）。
- 数词单元 ≤320ms 且不可截断；连点只保留最新待播数；总结句在最后一个数词后 180ms 起且只起一次；
  child-count 与 auto-count 互斥；动词横幅不朗读；每关口播为真实指令（"三跳到十二号！"）。
- 演示/揭示期间点屏幕任意处=快进到结果帧：进入 reveal 240ms 后布防、需全新 pointerdown、
  忽略触发提交的 pointerId，skip 的整个 pointer 序列被 reveal 层捕获消费，revealComplete 前手势层不收输入。

### 1.5 手势三律 + 词汇表
1. 一世界一条核心数学主线：W1 构造数量、W2 一一配对、W3 左右分配、W4 序数与分解、W5 逐一入位、W6 数轴跳。
2. 核心动词：W1 **甩**（flick 甩泥）、W2 **拖**（拖狗到海龟配对，安全带跟手）、W3 **滑**（左右滑发牌）、
   W4 **下拽**（L1/L2 摘第 n 个）与**划切**（L3/L4 选分解点，两动词分阶段互斥生效）、
   W5 **抛**（抛球入仓）、W6 **描弧**（亲手画数轴上的加法弧，落点吸附 1/2 格）。
   非核心事件手势（只触发事件/庆典）：W1L3 向下划唤雨、W2L4 沿坡划推舱、W5L3 画圈充能（一圈=一颗，圈数=数量）、W6L3 拖影对接。
3. 兜底与教学：每个手势都有点按等价（点云=下雨、点舱=滑下、点传送门=送一颗、点虚影=自动对接、
   点泥坑=原地弹、点狗=配最近落单、点盘=发往下一合法侧、点球=抛入、点花结=剪、点葫芦=摘、按钮=跳）；
   幽灵手 0.8s 演示，连续 2 次手势失败自动复教；手势失败=无事发生（不计错不出声）。

### 1.6 触控下限
热区 ≥64×64px（推荐 72）、中心距 ≥80px、边缘留 24px、容 20px 漂移；摆动的葫芦用静止槽位热区；
W6 跳跃按钮 112×88px 且画 ●/●● 点形图标；泥点从固定候选槽位按种子抽取不重叠。

### 1.7 确定性与测试契约
- 布局种子 {stageId,roundId}，重试不换布局；平距决胜按稳定 ID。
- 手势接受时归一化为 payload（{verb:'jump',span:2} 等）；**同种子+同 payload 序列 ⇒ 逐帧一致**；
  手指速度只影响 0–120ms 表演插值，不进 payload 不改落点。
- 数学状态在输入被接受瞬间一次性提交；动画/音频只读状态；快进与全播终态一致，revealComplete 只发一次。
- 钩子：actionAccepted / countChanged / speechStart/End / revealStart/Complete / skipRequested / verdict / __gesture / __fast。
- 必测：同种子逐帧一致、双击不误快进、同时语音数 ≤1、快进前后状态一致、最小视口热区达标。

### 1.8 四个通用内核
QuantityBuilder 数量构造器 / SlotRack 槽位架 / Allocator 左右分配器 / CommitFlow 提交演示控制器。
24 关全部是四内核+皮肤，不写 24 套状态机。

### 1.9 闪电轮（可选，Boss 节奏）
每 session 第 5 轮：同机制、动画 ×1.5 速、鼓点加速、数值取本 session 最大答对值 +1、庆典加倍。失败无惩罚。

## 2. 六个世界（玩法 × 关卡 × 翻转时刻）

### W1 佩奇泥坑 ·「会排队的泥点」· 动词：甩
玩法：闪现记忆 → 孩子**甩泥构造同样多**（甩的方向只是表演，落点=下一个种子槽位）→ 按「冲呀」提交。
- L1 快照构造（闪 3–5 个）；L2 红蓝两批合并构造总数；L3 孩子**向下划唤雨**，雨冲走 k 个（灰徽章飘出），构造剩下的；
  L4 拖篮子扣住一段，构造被扣住的（右侧小格板）。
- **翻转**：提交后大水花掀起乱泥，空中翻滚后**啪啪啪自动落成 2×5 十格**（落格只有鼓点无语音），
  原题同步排上行逐列绿闪对照。差异反馈：缺→空格闪黄"还差两个"；多→多的泥点自己跳回。
- 语音：开场"做出一样多！"；构造中只报数；总结"你做了五个——和刚才一样多！"

### W2 冒险湾 ·「救援配对拉链」· 动词：拖
玩法：**拖狗到落单海龟**配成对（安全带虚线跟手延伸），配好的对共享徽章 1,2,3…
- L1 全部配对；L2 已有 a 对灰色，只补落单的；L3 归队点名（车里的狗逐只点亮编号，重复点提示"已经数过啦"，
  点完车顶数字牌翻出总数）；L4 点狗=派双座舱（舱顶亮"2"）自动吸附一对海龟，按「出发」提交（舱数=对数）。
- **翻转（800ms）**：最后一对完成 → 80ms 蓄势 → 420ms 狗龟吸成两条平行轨道（每对错峰 45ms）→
  260ms 拉链头扫过 → "6/6"盖章。L4 另有舱阵折叠成 2×d 网格、边缘亮 2/4/6/8。
- 多派保护：空舱打哈欠滑回；多点的狗被门温和挡住（0.6s 无语音）。

### W3 Bluey 后院 ·「公平大天平」· 动词：滑
玩法：**左右滑=发牌到左右盘**，托盘上方实时数字气泡，板子角度=数量差映射（缓动 0.35s），放平"当~"+绿灯+数字碰杯。
- L1 谁多多几：往轻的一边逐块加平，金徽章计数，平了金徽章飞进"多几个"的 □——差=配平所需的量；
- L2 只许给 Bingo 加（对方盘上锁）；L3 强制交替发牌，**单数最后一块：任意第一次放置尝试（滑或点）都不落盘，
  立即自动演出左沉 400ms→右沉 400ms→退回中央聚光灯孤零零转圈**（演出后禁用放置，语音后收束）——
  "单数：总有一块配不成对"；双数：最后一块落下即水平锁定+彩带；
- L4 自由平分（n 限定偶数 6–12）：全部分完且左=右的最后一块落下才判定；分完不平→重盘弹出一块"这边太重啦"。

### W4 葫芦山 ·「花结与彩虹」· 主线：序数与分解（L1/L2 下拽 · L3/L4 划切）
玩法：藤上葫芦挂位置牌 1–7（永久尺子），葫芦间是 ≥72px 花结。
- L1 **下拽摘第 n 个**（静止槽位热区）：对→落地白烟变身；错→从起点侧位置牌逐个闪到它"这是第五个哦"。
- L2 倒着数（方向箭头沿藤跑一遍）。
- L3 **划过花结=剪**：左筐先站 x 个剪影，剪对→左段滑入逐个重合+徽章报数，算式 x+□=N 才从筐沿抽出；
  剪错→藤 400ms 回弹接好，剪影缺口闪黄"左边要三个，现在只有两个"。
- L4 分法收集（无序分法，7 收 1+6/2+5/3+4）：剪下的两段**各自卷成双色比例彩虹弧**（长度=数量），
  剪出镜像分法时两条彩虹旋转 180° 重合"换个边，还是七！"合并记账；一局集 2 组，进度跨局保存，集齐绽放。

### W5 复仇者 ·「能量十仓」· 动词：抛
玩法：计数单位=能量球（英雄只投球叙事）；**把球向机器一划=抛入下一空格**；屏显"目标 8｜已装 3/10"。
- L1 红队投完换蓝队（换弹匣音效），投完逐格点名清点，点完最后一格即提交显数；
- L2 断电：传送门吸走 k 颗（格逐个熄灭+灰徽章飘出），孩子逐格点亮剩余清点提交；
- L3 全息缺口：缺口格心跳闪烁，**画圈充能传送门（一整圈=送一颗，圈数=缺口数）**或点门，补到刚好即提交，满员再点"嗡"+屏抖；
- L4 凑十：亲手逐颗抛球；第 10 颗入仓瞬间**全仓金光→锁扣咔哒→盖"10"章→整仓收拢成一根十条**（1.2s 可快进），
  余 3 颗抛进第二仓，最后一颗入仓即提交，屏翻牌"10 和 3 = 13"。

### W6 花果山 ·「三颗仙桃」· 动词：描弧
玩法：12 格石墩数轴（刻度永久可见）+ 骑棒悟空 + 仙桃架 ×3（跳一次吃一颗变核）。
**手指从悟空所在石墩画一道拱弧落到目标石墩=跳**（落点吸附 1/2 格，更远弹性拒绝悟空摇头）；
弧顶挂 +1/+2 跨度徽章；按钮 ●/●● 兜底。
- L1 接着数；L2 二连筋斗（双数刻度金色）；L3 镜像翻倍（虚影段滑出，**拖影对接**或点它自动对接）；
- L4 三颗仙桃：起点 6/7、终点 11/12（金门在 10）；**出题器保证三跳总和 ∈{4,5} 且成功序列必含 1 和 2**；
  三跳用完自动提交；失败→悟空荡回、桃复原、上次弧链留虚影"一加二加一是四，还差一格"。
- **翻转（≤900ms）**：金色残影用**另一个不同的合法排列**重跳（3×220ms），双方落同一石墩，
  三段弧 180ms 压成一根 5 格金箍棒，棒身浮出"2+2+1=5"；跨十弧在金门自动分蓝金两截。
