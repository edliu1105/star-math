# 交付说明 · 星星回家

> 正式地址：**https://edliu1105.github.io/star-math/**

## 一、给孩子怎么用

1. **iPad 相机扫二维码** → 点弹出的横幅打开网页。
2. 进去先看到一颗大喇叭按钮 —— **让孩子自己点它**（这一下同时解锁了 iPad 的语音，很重要）。
3. 进入星空地图，六个世界。**一开始只开放前两个**（佩奇、汪汪队），玩到一定程度会自动解锁下一个。
4. 每次进一个世界玩 5 轮，大约 2–3 分钟，然后自动回到星空图。左上角房子随时可以回去。
5. 听不清指令时，**点左上角那个角色头像**就会再说一遍。

## 二、添加到主屏幕（强烈建议）

用主屏图标启动是**全屏无地址栏**的，孩子不会误触浏览器界面，而且离线也能玩。

1. 用 **Safari** 打开上面的网址
2. 点底部（或右上角）的 **分享** 按钮 ⬆️
3. 往下滑，选 **「添加到主屏幕」**
4. 名字保持「星星回家」，点 **添加**
5. 桌面上会出现一个深蓝夜空 + 金星星的图标，以后从这里进

> 第一次请**联网玩一遍六个世界各一关**，把图片灌进缓存；之后飞行模式也能完整玩。

## 三、家长面板（语音出问题时用它排查）

- **右下角长按 3 秒** → 出现一道算术题（防止孩子误入）→ 答对进入面板
- 面板里能看到：系统声音总数、中文声音列表、当前用的是哪个声音、**首句是否成功发声**、每个世界的进度与难度
- 有「测试发声」按钮
- 也有「清空进度」（需要点两次确认）

**iPad 没声音的排查顺序**：侧边静音开关 → 音量 → 有没有连着耳机/音箱 →「设置 → 辅助功能 → 朗读内容 → 声音 → 中文」下载一个中文声音。
**注意：即使一个中文声音都没有，这个游戏也完全可以玩** —— 所有指令都有对应的画面演示、发光提示和手指演示动画。

```bash

git add -A && git commit -m "..." && git push
```

推完之后，**在 iPad 上刷新一次页面**（或从主屏图标重开一次）就是新版本了。

## 九、这个应用到底在教什么

不是教孩子背「1、2、3」，也不是教「3+2=5」。六个世界各教一种**不同的**数学认知，顺序就是认知发展的顺序：

| 顺序 | 世界 | 认知 | 为什么重要 |
|---|---|---|---|
| 1 | 佩奇的泥坑 | **瞬识** | 不数就知道有几个。数感的生物学基础，先于计数，背不出来 |
| 2 | 冒险湾救援 | **一一对应 / 基数 / Give-N** | 「数到的最后一个数就是总数」—— 这是背诵与理解的分水岭 |
| 3 | Bluey 后院 | **比较 / 守恒** | 摆开还是挤紧，数量不变。检验孩子看的是外观还是数量 |
| 4 | 葫芦山 | **序数 / 部分-整体** | 5 由 2 和 3 组成 —— 加法的结构，不是算式 |
| 5 | 复仇者大厦 | **合并加法** | 加法最原始的含义：两堆合成一堆 |
| 6 | 花果山 | **接着数** | 从「全部重数」到「接着数」，是运算的第一次真正抽象 |

**每一题都必须孩子自己作答并主动提交**；答错走**分技能纠错**（瞬识用组块、基数才重数、守恒让孩子亲手一一配对、接着数保留已有只演示新增），然后换一道**同构新题复测**；只有「新题 + 没用提示」的首答才算掌握证据。一轮内最多错两次，之后系统一定给出答案、带着孩子做对、给星、进入下一轮 —— **不会有卡住的时候**。
