# v5.4 手势词汇表（并入 v5.3 交互规格 · WarioWare 级输入多样性）

## G4 手势三律（新增全局律）
1. **一关一动词，动词即手势**：每关的核心数学动作绑定一个专属手势（甩/滑/拖/画圈/描弧/按住），
   开场动词横幅同时演示手势的幽灵轨迹（幽灵手 0.8s 演示一遍，孩子任何输入立即接管）。
2. **人人可玩兜底**：每个手势都有点按等价操作（点也能完成，手势只是更爽）；手势判定极度宽容
   （命中走廊 ≥1.5× 目标尺寸、方向容差 ±35°、轨迹自动吸附）。
3. **测试等价接口**：所有手势收敛到 `window.__gesture(name,payload)`，真实手势和自动化测试走同一处理器。

## 逐世界手势设计

### W1 泥点 —— 动词：甩（flick）
- **甩泥**：手指从泥坑往场地一甩，泥点沿甩的方向飞出落地（速度决定距离，落点仍受场地约束）。
  比"点脚印"爽十倍：孩子在"甩出数量"。点泥坑 = 兜底（原地弹出）。
- **L3 唤雨**：轮到减法事件时，屏幕顶出现云，**孩子自己往下一划 = 下雨**——减法是孩子亲手触发的
  （雨冲走 k 个的名单由题目定，但"让雨落下"这个事件权交给孩子）。
- **L4 扣篮子**：孩子**拖动篮子**罩到泥点行上（吸附到格位），盖住哪几个由题目高亮指示（拖到指定区）。
- 删除泥点：把泥点**往泥坑方向一甩**扔回去（或点它）。

### W2 配对拉链 —— 动词：拖（drag-to-pair）
- **拖狗到海龟**：按住狗拖到落单海龟身上松手 = 配对成功拉链动画。拖动中安全带虚线实时从狗延伸到手指。
  点狗 = 兜底（自动跑向最近落单海龟）。
- **L4 推舱下坡**：双座舱停在坡顶，孩子**沿坡道向下一划 = 推舱滑下**（滑的速度映射下坡动画速度上限 1.2×）。
- L3 点名维持点按（点名本来就该点）。

### W3 公平大天平 —— 动词：左右滑（rhythmic swipe）
- **L3 轮流发**：屏幕中央出现待发饼干，**向左滑 = 发给左盘，向右滑 = 发给右盘**；强制交替时滑错方向，
  饼干飞到一半画一道弧改道（提示但不惩罚）。左-右-左-右的节奏感 = WarioWare 的心跳。
  单数结局：最后一块怎么滑都被两边"弹回来"（左滑左盘沉一下弹回、右滑同理），最终它悬在中央聚光灯。
- **L1/L2/L4 拖饼干上盘**：拖到盘上方松手；点饼干 = 兜底飞向轻的一边（L2 飞向 Bingo 盘）。

### W4 花结与彩虹 —— 动词：切（swipe-to-cut）
- **划过花结 = 剪断**（水果忍者式）：快速一划横穿藤蔓花结，剪刀沿轨迹咔嚓。命中走廊 = 花结直径 ×1.6。
  点花结 = 兜底。
- **L1/L2 摘葫芦：在目标葫芦上向下一拽 = 摘**（拽的动作和"从藤上摘下来"物理同构）；点 = 兜底。

### W5 能量十仓 —— 动词：投（swipe-to-throw）+ 画圈（circle-to-spin）
- **投球**：把排队的能量球**向机器方向一划 = 抛入**（抛物线飞行 0.4s 入下一空格）；点球 = 兜底。
- **L3 转传送门**：**在传送门上画一个圈 = 充能转一圈送来一颗球**（画圈角度累计 ≥300° 判定）；
  点传送门 = 兜底。缺几颗就要画几圈——圈数=数量，手势本身在数数。
- L2 断电是页面事件（吸走），孩子随后逐格点亮清点（点按）。

### W6 三颗仙桃 —— 动词：描弧（trace-the-arc）
- **描跳**：手指从悟空所在石墩**画一道拱弧落到目标石墩** = 跳。轨迹吸附：终点落在下 1 格判"跳1"、
  下 2 格判"跳2"（更远则弹性拒绝，悟空摇头）。描的弧就是数轴上的加法弧——孩子在亲手画数学。
  按钮「跳1」「跳2」保留 = 兜底（也是残影演示用的可视化）。
- **L3 拖影翻倍**：镜像虚影段出现后，**孩子亲手把虚影段拖到棒尾接上** = 完成翻倍（吸附对接，接上金光）。

## 第五轮=闪电轮（WarioWare Boss 节奏，可选实现）
每个 session 的第 5 轮进入**闪电轮**：同关卡同机制，动画×1.5 速、鼓点 BGM 加速、
题面数值取本 session 孩子答对过的最大值 +1；通关庆典加倍（星轨双倍粗）。
失败无惩罚，只是庆典普通。给"我还想再玩"一个心跳理由。

## 手势工程红线
- pointerdown/move/up 统一手势层，阈值：位移 ≥24px 判滑、≥300ms 静止判长按；采样 30Hz 折线简化。
- 画圈：相对锚点累计转角；描弧：只取起终点+最高点验证"拱形"，不做逐点匹配。
- 所有手势失败 = 无事发生（不计错不出声），连续 2 次失败手势自动弹幽灵手复教。
- `window.__gesture` 直通处理器；`__fast=1` 下手势动画归零。
