# 星星回家 · 幼儿数感建构互动应用

给 3 岁半 – 4 岁、说中文、还不识字的孩子。目标只有一个：**真正理解数字、数量与加法 —— 是理解，不是背诵。**

单个 `index.html` + `assets/`，vanilla JS/CSS，零外部依赖，PWA 离线可玩。目标设备 iPad（Safari / Chrome）。

---

## 玩什么

> 夜里刮了一场大风，天上的星星被吹落到六个世界。帮朋友们一次忙，就找回一颗星星。
> 星星飞回天上，连成星座。六个星座都亮起来时，天空就修好了。

六个世界，每个教一种**不同**的数学认知，玩法直接来自角色本身的能力：

| 世界 | 角色 | 数学认知 | 玩法机制 |
|---|---|---|---|
| 🐷 佩奇的泥坑 | 佩奇、乔治、猪爸爸、猪妈妈 | **瞬识 Subitizing** | 跳泥坑溅起泥点，只闪 1 秒 —— 来不及数，只能"一眼看出几个" |
| 🚒 冒险湾救援 | 莱德、阿奇、毛毛、天天、灰灰、路马、小砾 | **一一对应 / 基数原则 / Give-N** | 点数小海龟 → 必答"一共几只" → 按数量卡派出正好那么多狗狗 |
| 🐕 Bluey 的后院 | Bluey、Bingo、爸爸 Bandit、妈妈 Chilli | **比较 / 数量守恒** | 分东西要公平；爸爸把一排摆开一排挤紧 —— 谁的多？（皮亚杰守恒实验游戏化） |
| 🎋 葫芦山 | 七个葫芦娃、爷爷、蛇精、蝎子精 | **序数 / 部分-整体（缺失加数）** | 第几个葫芦成熟了？山洞已有 2 个，山顶还要几个才够 5 个？ |
| 🛡️ 复仇者大厦 | 铁甲侠、星盾队长、雷锤、绿力士、黑寡妇、鹰眼、蛛网小子、暗蛛侠 | **合并加法 / 接着数 / 够不够** | 两边英雄集结合成一队，一起数总数；每个英雄抓一个坏蛋，够不够？ |
| 🍑 花果山 | 孙悟空、唐僧、猪八戒、沙僧、白龙马 | **数轴 / 接着数 Count-On** | 金箍棒 = 数轴。已经有 3 格了，再变长 2 格 —— 从 3 接着数，不用从头数 |

学习路径完整覆盖：**量感 → 计数 → 基数 → 比较 → 守恒 → 结构 → 运算 → 符号**。

## 怎么防止"背诵通关"

- 每题都必须**孩子自己作答并主动提交**，系统在作答前不给任何提示
- 答案卡 **4 选 1**（不是 3 选 1），且**答案的点阵排列与题面排列必定不同** —— 封死"图形匹配"
- 答错 → **分技能纠错**（瞬识用组块、基数才重数、守恒让孩子亲手一一配对、接着数保留已有部分只演示新增），再换**同构新题复测**
- **复测题与用过提示的题不计入掌握证据**
- 升级判据：最近 5 次首答里 ≥4 次正确；降级：最近 4 次里 ≤1 次正确
- 数字符号全局最后解锁（至少两个世界达到 L3 才出现阿拉伯数字）

## 三岁半可用性

- 界面**零文字依赖**：全语音 + 图标 + 动画演示；**全应用零拖拽**，一律"点一下"
- 分级提示：9 秒发光 → 18 秒重播指令 → 28 秒手指演示（永不替孩子作答）
- 无红叉、无失败音、无扣分；每一轮都能拿到星星
- 家长入口：右下角长按 3 秒 → **成人算术验证** → 语音诊断 / 进度 / 重置

## 目录

```
index.html                单文件应用（HTML + CSS + JS 全内联）
assets/chars|thumbs|props|bg   美术素材（GPT Image 2 生成 → PIL 优化）
manifest.webmanifest      PWA
sw.js                     Service Worker（页面网络优先 / 素材缓存优先）
tests/test_app.py         Playwright 发布门槛测试
tests/smoke.py            快速视觉冒烟
tools/                    素材生成、优化、接触印像、二维码
docs/                     设计方案、评审 brief、评审回应
shots/                    截图与测试日志
```

## 本地预览

```bash
python -m http.server 8817
```

然后打开 http://localhost:8817 。（`.claude/launch.json` 已配好同样的命令。）

## 测试

```bash
python tests/test_app.py --browser webkit
```

`--browser chromium` 也可以。WebKit 是 iPad Safari 的同源引擎，以它为准。

## 更新方法

改代码 → `git push` → 在 iPad 上**刷新一次**即可生效。
（`sw.js` 对页面用网络优先 + 2.5 秒超时，所以新版本不会被旧缓存挡住；素材用缓存优先，所以离线仍然完整可玩。）
